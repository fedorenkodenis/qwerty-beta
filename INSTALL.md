# Установка QWERTY

Это пробная установка QWERTY для бета-тестера. Нужен Mac с macOS 26 или новее, Apple Silicon или Intel.

**Установка через Finder.** [Скачай QWERTY.dmg](https://github.com/fedorenkodenis/qwerty-beta/releases/download/beta/QWERTY.dmg), открой образ и перенеси QWERTY в «Программы». Если macOS запросит подтверждение, используй стандартный пункт «Всё равно открыть» в разделе «Конфиденциальность и безопасность».

## Установка через Терминал

1. Открой «Терминал» через поиск Spotlight — ⌘ Пробел.
2. Скопируй всю команду ниже в Терминал и нажми Enter.

```sh
curl -fsSL https://raw.githubusercontent.com/fedorenkodenis/qwerty-beta/main/install.sh | /bin/sh
```

Дождись сообщения об успешном запуске. Приложение появится в «Программах» и откроет приветствие. Пройди шаги приветствия и подтверди разрешения macOS на работу с клавиатурой.

Если команда сообщила об ошибке, скопируй её итоговое сообщение разработчику. В нём будет этап, на котором остановилась установка. Отчёт установки содержит технические сведения без набираемого текста и автоматически никуда не отправляется.

## Что делает команда

Скачивает бета-сборку с GitHub, сверяет размер и контрольную сумму, проверяет подпись и совместимость с Mac. Затем копирует QWERTY в общие «Программы» или, если у пользователя нет туда доступа, в его личные «Программы». С установленной копии снимается метка интернет-загрузки. Это помогает пройти первый запуск бета-приложения, которое пока не нотариализовано Apple.

Прежняя установленная версия сохраняется до подтверждённого запуска новой. При сбое запуска установщик пытается вернуть её на место. Настройки и исключения хранятся отдельно от приложения.
